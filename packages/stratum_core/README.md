# stratum_core

Чисте Dart-ядро гри STRATUM: тік-рушій, стан симуляції, конфіг балансу,
офлайн-розрахунок. Без імпортів Flutter — щоб баланс перевірявся прогоном
тіків у звичайному `dart test`, а не в емуляторі.

Еталон поведінки — прототип `prototypes/Stratum.dc.html` у корені репозиторію.
Числа ядра мають збігатися з ним (тести паритету), див. `CLAUDE.md`.

```sh
dart test          # з теки packages/stratum_core
dart analyze
```
